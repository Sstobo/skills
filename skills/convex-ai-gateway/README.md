# convex-ai-gateway

Call AI models from Convex actions through the Convex AI Gateway, with no provider accounts or API keys. Covers the Vercel AI SDK provider, the OpenAI SDK pointed at the gateway, the Agent and RAG components, embeddings, image and video generation, errors and spend limits.

## Use it when

- Adding chat, summaries, RAG, embeddings or classification to a Convex app
- Swapping models
- Debugging gateway errors

## Install

```bash
npx skills add Sstobo/skills --skill convex-ai-gateway
```
