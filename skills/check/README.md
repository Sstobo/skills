# check

Sends a skeptical senior engineer (a fresh subagent with no stake in the work) to look over what was just done in the session and report real problems only. No nitpicks, no praise padding.

## Use it when

- You finished a chunk of work and want a second pair of eyes
- Something feels off but you can't say what

## Install

```bash
npx skills add Sstobo/skills --skill check
```
