# better-auth-convex

Set up, repair and troubleshoot Better Auth on Convex + TanStack Start with `@convex-dev/better-auth` (0.12.x). Covers sign up/in/out, SSR with `expectAuth`, triggers for an app-owned users table, and the common failure modes: stale tokens, white screens, queries firing before auth is ready, hanging loaders.

## Use it when

- Adding auth to a Convex + TanStack Start app
- Auth works sometimes and you need it reliable
- Looking up the component client API or plugins

## Install

```bash
npx skills add Sstobo/skills --skill better-auth-convex
```
