# convex-helpers

Reference for `convex-helpers`, the utility library that complements the official Convex packages: custom functions, relationships, row-level security, sessions, rate limiting, pagination and more.

## Use it when

- Building custom query/mutation wrappers with auth
- Walking relationships between tables
- Reaching for a common Convex pattern that already exists

## Install

```bash
npx skills add Sstobo/skills --skill convex-helpers
```
