# inquisitor

Interrogates a project, feature, plan or decision from the outside. Tears down assumptions, exposes blind spots and surfaces inconvenient truths, delivered as an evidence-backed verdict ranked by damage.

## Use it when

- Stress-testing a plan before committing to it
- "What am I missing?"
- Playing devil's advocate on a decision

## Install

```bash
npx skills add Sstobo/skills --skill inquisitor
```
