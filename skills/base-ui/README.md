# base-ui

Practical guide to building UI with `@base-ui/react`: installing, styling, animating and composing components such as Dialog, Popover, Select, Combobox, Menu, Tabs, Toast and Field/Form, plus fixes for portal, anchor and state-attribute issues.

## Use it when

- Adding or styling a Base UI component
- Wiring forms and validation
- Debugging positioning or data-attribute styling

## Install

```bash
npx skills add Sstobo/skills --skill base-ui
```
