# convex-tanstack

Minimum best practices for wiring Convex into TanStack Start via `@convex-dev/react-query`: setup, data loading, SSR and the patterns that keep it fast and correct.

## Use it when

- Starting a Convex + TanStack Start project
- Reviewing how an existing app fetches Convex data

## Install

```bash
npx skills add Sstobo/skills --skill convex-tanstack
```
