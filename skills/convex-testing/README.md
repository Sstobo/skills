# convex-testing

Write and set up automated tests for Convex queries, mutations, actions and HTTP endpoints with `convex-test` and Vitest.

## Use it when

- Setting up testing in a Convex project
- Adding tests for a Convex function

## Install

```bash
npx skills add Sstobo/skills --skill convex-testing
```
