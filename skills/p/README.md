# p

Sweeps up everything in the working tree into one clean commit and pushes to main. Leaves out secrets and junk and names them in the report. Built for solo trunk-based development.

## Use it when

- You want everything committed and pushed in one go

## Install

```bash
npx skills add Sstobo/skills --skill p
```
