# okf

A repo's knowledge layer: small markdown docs that hold what the code can't say, each declaring the code files it's about. Four frontmatter fields, no engine, no timestamps. Docs are verified by reading them against their sources when you work in that area. Includes a repair pass for drifted docs.

## Use it when

- Writing or fixing project docs
- Deciding whether something belongs in a comment or a doc
- Finding which docs cover a file you're changing

## Install

```bash
npx skills add Sstobo/skills --skill okf
```
