# avatar

Builds a verified, complete picture of one thing in your project (a feature, system, bug or decision): what it is, where it lives, how it connects, what the docs say and how it got that way. Researcher agents gather the facts, challenger agents try to knock them down, and only confirmed detail lands in the final HTML reader.

## Use it when

- You need to fully understand a feature before changing it
- Docs and code might disagree and you want to know where
- You want the history behind a decision

## Install

```bash
npx skills add Sstobo/skills --skill avatar
```
