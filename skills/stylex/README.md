# stylex

Author styles with StyleX (`@stylexjs/stylex`), Meta's build-time atomic CSS library: tokens, themes, pseudo-classes, media queries, keyframes, dynamic styles, and build setup for Vite, Next.js, Webpack and others.

## Use it when

- Writing or reviewing StyleX styles
- Defining design tokens or themes
- Setting up or debugging the StyleX build

## Install

```bash
npx skills add Sstobo/skills --skill stylex
```
