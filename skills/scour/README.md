# scour

Read-only auditor. Points a swarm of doc-armed agents at one area of a codebase to hunt shallow modules, oversized files, convention drift and untestable seams. Every finding survives an adversarial verification pass, then becomes a ticket that `ship-it` can build.

## Use it when

- Quality-passing a crufty area of the codebase
- Turning an audit into agent-ready tickets

## Install

```bash
npx skills add Sstobo/skills --skill scour
```
